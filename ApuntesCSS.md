                             SELECTOR
                             Indica que elemntos HTML queremos modificar

                                -Selector de etiqueta
                                -Selector de clase
                                -Selector de ID

    SELECTOR DE ETIQUETA

        p {
            color:blue;
        }

        afecta a todos los <p></p> del html


    SELECTOR DE CLASE

    Tu lo puedes definir, tomar el nombre el nombre q tengamos


       .destacado {
        color:red;
       }

       Una clase puede utilizarse en varios elementos 


       TODAS LAS CLASES COMIENZAN CON UN PUNTO


    <p class="destacado">Texto importante</p>     Aqui solo le afecta a este parrafo seleccionado

        Para modificar algo muy especifico, el selector de id comienza con un #
